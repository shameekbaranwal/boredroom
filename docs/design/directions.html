How they're made

Layout × finish

Puzzle Page and Spreadsheet are layouts: tiles and slab headings, or cells and a formula bar. Riso and Night are finishes: two-ink print with grain, or pastel on navy. Each cell crosses one of each. Pick any to try it on the bench.

Motion

Small moves, almost no cost

Every animation is a CSS opacity or transform change, or a short width or height change. No JavaScript animation loops, no canvas, no libraries. Riso grain is one static background pattern. All motion switches off under reduced-motion.
